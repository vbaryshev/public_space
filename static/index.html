Добро пожаловать на портал

На этом портале вы можете просматривать и анализировать точки интереса (POI) на карте, а также выполнять операции с ними. Документация по API: FastAPI.

Загружайте и просматривайте сырые POI и их варианты визуализации.
Интегрируйте свой бэкенд на FastAPI для выдачи данных и метаданных.

Модель посещаемости общественных пространств

- исторические данные;
- гравитационная модель;
- байесовская сеть;
- симуляция Монте-Карло;
- A/B тест новых данных

Подсказка

  • Серые точки — сырые POI до симуляции
  • Цветные круги — результат симуляции (радиус ~ среднедневные визиты)
  • Клик по точке — всплывающее окно с типом и среднедневными визитами
